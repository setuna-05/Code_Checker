Code Checker 使い方
====================

■ これは何?
Pythonのコードを、ruff(書き方の間違い)・mypy(データの種類の食い違い)・
bandit(安全面で危ない書き方)の3つのツールで自動チェックし、
結果をAI(Claudeなど)に貼り付けやすい「レポート」にまとめるアプリです。
Claudeが書いたコードだけでなく、他のAIが書いたコードや、自分で直したコードも、
同じ基準で調べられます。


■ 最初に1回だけ(準備)
1. このzipファイルを「すべて展開」して、できたフォルダを好きな場所に置きます。
   (zipの中から直接ダブルクリックしないでください)
2. フォルダの中の「1_setup.bat」をダブルクリックします。
3. 黒い画面が開き、ツールの導入が始まります(数分かかることがあります)。
4. 「Setup finished.」と出たら完了です。何かキーを押して閉じます。
   途中で「Building it again without the C++ part」と出ることがあります。これは正常です(bandit用の部品を作り直しています)。
   途中で [ERROR] と出たときは、黒い画面の文字をすべてコピーして、AIに貼り付けてください。


■ ふだんの使い方
1. 「2_start.vbs」をダブルクリックします。
   黒い画面は出ず、Code Checker の画面だけが開きます。
   (起動に失敗したときだけ、エラーの文字が入った黒い画面が開きます)
2. 「ファイルを選ぶ」または「フォルダを選ぶ」で、チェックしたい対象を選びます。
3. 「チェックを実行」を押します。少し待つと、画面に「まとめ」が出ます。
   - 問題なし … 緑
   - 問題あり(○件) … 赤
   - チェック未完了 … オレンジ(ツールが動かなかったとき)
4. 「レポートをコピー」を押し、AIの入力欄に貼り付けて、判断を相談します。
   「ファイルに保存」を押すと、レポートをテキストファイルにできます。


■ レビュー画面
「レビュー画面を開く」を押すと、どのコードのどこが指摘されたかを確認できます。
- 左の一覧から問題を選ぶと、右にそのファイルのコードが出ます。
- 選んだ問題の行は赤っぽく、同じファイルの他の問題の行は茶色っぽく光ります。
- 上の「絞り込み」で、ツールごとに表示を切り替えられます。
- 下に、ツール名・ルール名・重大度・場所・内容(ツールが出した英語の文章のまま)が出ます。


■ 大事な注意
- 「問題なし」でも、実機で正しく動く保証ではありません。
  このアプリが調べるのは、書き方・データの種類・安全面の機械的なチェックだけです。
  動かして確かめる(実行テスト)の代わりにはなりません。
- 選んだファイルやフォルダの中身は、書き換えません(読むだけです)。
- 3つのツールとも、チェック対象にある設定ファイルは読み込まず、毎回同じ基準で調べます。
- ruff … 調べるルールは E4, E7, E9, F に固定しています。
- mypy … 「外部ライブラリが見つからない」という警告は出さない設定です。
  (このアプリ専用の環境には、チェック対象が使う外部ライブラリが入っていないためです)
- bandit … 標準の設定です。
- .venv、venv、node_modules、build、dist などのフォルダは、チェックの対象から外します。
- チェックするのは拡張子が .py のファイルだけです(3つのツールで調べる範囲をそろえるため)。


■ ツールを新しくしたいとき
「1_setup.bat」をもう一度ダブルクリックすると、3つのツールが最新になります。


■ うまく動かないとき
- 起動に失敗すると、エラーの文字が入った黒い画面が開きます。文字をすべてコピーしてAIに貼り付けてください。
  (同じ文字は、フォルダの中の「start_log.txt」にも残ります)
- 起動しても何も起きないときは、「2_start.bat」をダブルクリックして、黒い画面を出して試すこともできます。
- 画面の見た目がおかしいときは、エラー文と、画面の画像(png)も一緒にお願いします。


■ ファイルの説明
- code_checker.py … アプリ本体
- 1_setup.bat      … 最初に1回だけ実行する準備用
- 2_start.vbs      … ふだん使う起動用(黒い画面が出ません)
- 2_start.bat      … 2_start.vbs が裏で使う起動用(黒い画面つきで試したいときにも使えます)
- start_log.txt    … 起動時のメッセージの記録(起動のたびに作り直されます)
- 使い方.txt       … このファイル
- .venv フォルダ   … 1_setup.bat が自動で作る、このアプリ専用のツール置き場(消しても、もう一度1_setup.batで作れます)
